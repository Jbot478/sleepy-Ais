# sleepy-Ais

A tiny mobile-friendly browser game where Ais tries to stay awake through movie night.

## Play locally

Because this is a static app, open `/home/runner/work/sleepy-Ais/sleepy-Ais/index.html` in a browser.

## Gameplay

- Opening scene introduces John, Saz, Katie, and Ais on the couch.
- Tap/click to make Ais's 👁️ float through obstacles.
- If you collide with obstacles or drift out of bounds: **"ooop you fell asleep"**.
- Survive for 5 minutes: **"hurray you made it though the movie"**.
- Retry anytime from the result screen.
